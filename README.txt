GitHubへの更新方法
1. ZIPを解凍
2. GitHubのV-RE-DUOリポジトリで Add file → Upload files
3. ZIP内のファイルをすべて選択
4. Commit changes
5. 1〜3分後、Safariでページを再読み込み
6. 古い表示が残る場合はSafariの再読み込みボタンを長押し、またはプライベートブラウズで確認
