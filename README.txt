V-RE:DUO 企業サイト完成版（iPhone用・フラット構成）

この版はフォルダがありません。
iPhoneのファイル選択画面で「すべて選択」を押し、表示される全ファイルをまとめてGitHubへアップロードできます。

更新手順
1. ZIPを解凍
2. 解凍したフォルダを開く
3. 「すべて選択」を押す
4. GitHubの Add file → Upload files でアップロード
5. Commit changes
6. 1〜3分後に公開サイトを再読み込み

重要
- ZIP自体をGitHubへアップロードしても自動展開されません。
- index.htmlを含む全ファイルを選んでください。
- 古いフォルダ assets / members / pages がGitHubに残っていても表示には影響しません。
